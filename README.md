# Comic Book

基于 [Mihon](https://github.com/mihonapp/mihon) v0.21.2 的个人 Android 漫画阅读器分支。Android 8.0 及以上。

本分支使用独立包名，可与原版共存；保留书架、中文界面、翻页/条漫、离线下载和备份。默认不编入遥测组件，关闭原版 APK 自动更新检查。未添加广告 SDK。

## 一次配置，聚合搜索

新首页是「漫画聚合搜索」：首次粘贴一个可信图源订阅地址，点击「保存并准备全部图源」。应用在内部自动下载、验证并加载订阅提供的中文源，不需要逐个安装扩展 APK，也不需要 Android 的逐包安装确认。

输入漫画名称后点击「搜索全部图源」，结果按来源展示。选择一个结果即可查看章节并阅读；某个来源较慢或失效时，返回搜索结果选择其他来源。最多五个来源并发搜索，每个来源设独立超时，错误和空结果不会阻塞其他来源。

服务器地址和源清单只通过运行时订阅获得，不包含在公开源码或默认 APK 中。原版只有一个已配置仓库的旧安装升级后会自动尝试接入。订阅中的解析模块在应用私有目录保存，不作为独立 Android 应用安装。

启动时在过期或未准备好时自动同步，并通过 WorkManager 约每 24 小时同步一次。图源签名需匹配订阅身份；后续同步固定签名身份，拒绝静默更换；已安装版本不降级，文件替换失败保留旧版。源站改版仍需要上游修复相应解析模块。

漫画图片继续由手机直接获取。书架、历史、阅读器、离线下载和备份继续保留；存储目录可在设置中按需配置。

## APK 构建

在 Actions 中运行 **Build APK**。成功后下载 `comic-book-apk` artifact，包含各架构/通用 APK 和 SHA256 校验值。正式使用需从本仓库对应构建下载，不使用 Mihon 原版 APK 覆盖本分支。

工作流先规范格式、运行单元测试和数据库迁移检查，再构建签名 APK。配置运行时测试订阅 Secret 时，还会在 Android 模拟器中验证一次订阅自动加载及多来源搜索；测试地址不会写进源码。签名材料通过 GitHub Secrets 提供：`SIGNING_KEY`（PKCS12 的 Base64）、`KEY_STORE_PASSWORD`、`ALIAS`、`KEY_PASSWORD`。这些值不能提交到 Git。每次升级递增 `versionCode`，保持签名密钥和包名不变；签名备份由仓库所有者自行保存在仓库外。

服务器部署、定时计划、源仓库配置和个人数据不属于此公开仓库。这里不发布任何个人服务器地址、凭据或源清单。
